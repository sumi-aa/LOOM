# Where every piece of text lives

Open `content.json` and change the words **inside the quotes after the colon**.
Leave the key (the name before the colon) alone — or rename it, it still works.

```
  "some_key":  "This is what shows on the site"
   ^ ignore     ^ edit this
```

Tags like `<b>` and `<em>` colour a word. Keep them if you want the highlight.
Numbers like `73%` or `2,400+` animate — just type the new number the same way.
